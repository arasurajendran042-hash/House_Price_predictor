Data Preprocessing

Raw data almost always has issues — missing entries, duplicates, inconsistent formats, and outliers. Preprocessing ensures the data is clean, consistent, and ready for Machine Learning.

Preprocessing Steps
  1. Load Dataset — Read the CSV file into a Pandas DataFrame
  2. Handle Missing Values — Fill blanks with median (numerical) or mode (categorical)
  3. Remove Duplicates — Drop identical rows that inflate the dataset
  4. Fix Inconsistencies — Correct negative ages and zero-area records
  5. Encode Categories — Convert text columns to numbers the model can use
  6. Scale Features — Normalise values so no single feature dominates
Missing Values

Columns with missing entries before imputation. We used median for numbers and mode for categories because median resists outliers and mode is the most frequent value.

Encoding Methods
ColumnEncodingHow It WorksWhy This Method
Furnishing Label Encoding Unfurnished→0, Semi-Furnished→1, Fully Furnished→2 Categories have a natural order (less→more furnished)
City, Property_Type One-Hot Encoding Creates a binary 0/1 column per category, drops one to avoid multicollinearity No natural ordering — label encoding would falsely imply “Mumbai > Chennai”
Location Target Encoding Replaces each location with the median house price of that area 60 unique locations — one-hot would create too many sparse columns
Key Takeaway: Different categorical variables need different encoding strategies. Using the wrong method can mislead the model — for example, label-encoding unordered categories makes the model think one category is "larger" than another.

Descriptive Statistical Analysis

Descriptive statistics summarise and describe the main features of a dataset. They help us understand the data before building any models.

Central Tendency

Central tendency measures tell us where the "centre" of the data lies.

  • Mean — The arithmetic average. Sensitive to outliers.
  • Median — The middle value when data is sorted. Robust to outliers.
  • Mode — The most frequently occurring value.

Measures of Dispersion

Dispersion measures tell us how spread out the data values are.

  • Variance — Average of squared differences from the mean.
  • Standard Deviation — Square root of variance, in the same units as data.
  • Range — Difference between maximum and minimum values.
  • IQR (Interquartile Range) — Range of the middle 50% of data (Q3 − Q1).

Inferential Statistics & Probability

Inferential statistics allow us to make conclusions about an entire population based on a sample. This section covers sampling, probability, and hypothesis testing applied to housing data.

Sampling Techniques

We rarely have access to the entire population. Instead, we draw samples and use them to estimate population parameters.

  • Simple Random Sampling — Every record has an equal chance of being selected.
  • Systematic Sampling — Select every k-th record from the dataset.
  • Stratified Sampling — Divide data into groups (strata) and sample proportionally from each.
Sample Means Comparison

Different sampling methods produce slightly different sample means. Stratified sampling often produces estimates closest to the population mean.

Law of Large Numbers

As we increase the sample size, the sample mean converges to the population mean.

Hypothesis Testing

Hypothesis testing lets us make data-driven decisions about whether an observed pattern is statistically significant.

  • Null Hypothesis (H0) — The default assumption (no difference / no effect).
  • Alternative Hypothesis (H1) — What we want to test (there IS a difference).
  • Significance Level (α) — Typically 0.05 (5%). If p-value < α, we reject H0.
  • P-value — The probability of observing such extreme results if H0 is true.

Calculus & Gradient Descent

Calculus provides the tools to optimise our model. The goal is to minimise the cost function (prediction error) by iteratively adjusting the model's weights.

Cost Function (MSE):   J(w, b) = (1/n) × Σ(ŷ − y)²
Gradient (weight):   ∂J/∂w = (2/n) × Σ x·(ŷ − y)
Update Rule:   w = w − α × ∂J/∂w     (where α = learning rate)
